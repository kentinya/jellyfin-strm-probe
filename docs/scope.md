## 包含

- 读取现有 STRM 中的版本标记、URL、SHA-1 和 Size。
- 包装或经验证的其他方式接入 Jellyfin 媒体源流程。
- 变化判断、首次接管、SQLite 状态、探测协调和真实成功验证。
- `ShortcutPath` 同步、原生媒体流复用、禁用／故障原生委托。
- 插件配置页面、脱敏诊断、隔离测试与版本限定的发布材料。

## 排除

- STRM 生成、OpenList 文件扫描／元数据抓取、批量写入、原子替换程序。
- 插件改写 STRM、计算远程视频哈希或调用 OpenList 元数据 API。
- JellyfinProxy 代码变更、关闭其完整 JSON 缓存、改变 302 映射缓存策略。
- 全库定期无条件探测、完整 PlaybackInfo 缓存、跨版本通用二进制承诺。
- 修改生产媒体、现有 Jellyfin 配置或生产数据库。

人工编写的 STRM 测试夹具用于验证解析与版本变化；它们不构成一个生成程序。T14、T15 使用测试目录里重新放置／重写夹具的方式验证插件行为，不要求开发生成器。
