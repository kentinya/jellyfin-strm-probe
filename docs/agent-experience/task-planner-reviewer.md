# B — Task 规划／审查经验

以下为 [mediaflow 最新流程](../references.md) 中适用于本项目的方法参考，尚不是本项目实机验收经验。经验不能替代合同、实际代码或原始证据。

- 按文件拆任务会打断用户结果 → 从已提交 Slice 选择跨必要层的完整行为 → 适用于 Task 规划。
- 重复全量验证增加等待但未必增加证据 → 按风险安排开发反馈和最终门槛，独立复现关键行为并核验匹配证据 → 适用于审查与修正循环，不能削减 T4 门槛。
- 范围问题被误当成测试问题 → 交回 A 修改合同，再明确判断 Task 合法性；每次 PASS 重新检查全部 RO → 适用于发现义务变化或决定停止规划。

每个 Slice 关闭时只补充 1～3 条可复用的新经验；合并重复、替换过时内容，无新经验不凑数。不记录 Task 历史、提交号或测试计数。
