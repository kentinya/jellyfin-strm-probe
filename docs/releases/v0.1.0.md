首个正式发布版本，插件版本为 `0.1.0.0`。本页保留发布时的交付事实；后续同一原 ZIP 的针对性兼容验证见下方支持范围，不改变既有 Release 附件或标签。

### 功能

- 按版本化 STRM 的 URL、有效内容 SHA-1 和 Size 决定是否需要 Jellyfin 原生探测，未变化时复用已有媒体流；URL 改变一律探测。
- 首次接管默认信任已有主流，避免全库重探测；后续仅在本次探测成功、原生结果已保存且 STRM 未再变化后提交指纹。失败保留旧基线，修复后重试。
- 提供原生计划任务「STRM 媒体信息检查」，支持所选库批量检查、停止、定时和进度；播放与批量共用并发限制，默认 2、可设 1～8。
- 包含视频主流结果匹配及 ColorRange 持久化往返修正。

### 支持范围

发布时已实测 **Jellyfin 12.2.0、Linux x64、MP4／MKV（H.264／AAC）、原生 Web 客户端**，当时 Jellyfin 12.3 尚未实机验证。后续同一原 ZIP 已在 Jellyfin 12.3.0／Linux x64 完成[Slice 6 六组针对性兼容回归](../progress.md#slice-6-closed)；原 12.2 全量验收与 12.3 最小实证分别报告，不宣称 12.3 千项容量、完整扫描或全格式兼容。其他平台／架构、音频 STRM、JellyfinProxy 及其他客户端不在本版兼容承诺内。

插件只读现有版本化 STRM，不生成 STRM、不下载远程媒体计算哈希。无可比 SHA-1 且 URL／Size 都相同的远程替换可能无法识别。独立扫描和检查计划不保证顺序执行。

### 下载和安装

下载下方 `Jellyfin.Plugin.StrmProbeOptimizer_linux-x64.zip`；同时下载来源清单、`.zip.sha256` 和 `SHA256SUMS.txt` 以便校验。GitHub 自动提供的 Source code 归档是源码，安装使用上述插件 ZIP。

```bash
sha256sum -c SHA256SUMS.txt
```

停止 Jellyfin，将 ZIP 内的整个 `Jellyfin.Plugin.StrmProbeOptimizer_0.1.0.0/` 目录解压到 Jellyfin 插件目录，再启动并在「控制台 → 插件」确认 Active。容器中通常为 `/config/plugins/`。配置、备份和恢复步骤见[安装说明](https://github.com/kentinya/jellyfin-strm-probe/blob/v0.1.0/docs/package-installation.md)。
