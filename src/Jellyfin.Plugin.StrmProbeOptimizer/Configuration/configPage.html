STRM Probe Optimizer

本页配置 STRM 优化的运行参数。固定判断规则（URL 变化必探测、SHA-1／Size 决策、修改时间不触发探测、 allowMediaProbe=false 不升级、首次信任与批量仅按需处理）始终生效，不作为可关闭的开关。 运行、停止、定时与进度仍由 Jellyfin 原生计划任务负责。

运行配置

关闭只影响播放入口；关闭后仍可独立运行「STRM 媒体信息检查」批量任务。保存成功后对下一次检查请求生效。

批量媒体库范围

开启时批量任务检查所有媒体库。关闭后可显式选择部分媒体库；此时必须至少选择一个，空选择不会自动扩大为全部。
页面展示媒体库名称，保存时写入其稳定 Jellyfin 库 ID。范围修改只对下一次批量运行生效。 已保存的库被删除或无法识别时，任务会报告范围不可用且不开始探测；请在本页修正后重新保存。

运行与恢复

原生任务入口：「控制台 → 计划任务 → STRM 媒体信息检查」。可在该处手动运行、 停止、查看进度与历史，并设置触发时间。默认没有自动触发时间， 新安装不会自动运行。运行／停止／定时始终由 Jellyfin 管理，本插件不提供独立入口。

停止任务只撤销尚未实际开始的工作；已经开始的探测会完成保存与指纹提交后，任务才以取消结果结束， 收尾结束后才能开始下一轮。单项失败修复后可重新运行任务。

状态库故障恢复：若指纹状态库不可用，批量任务会停止后续优化并报告不可用，不会退化为全库强制探测。 停止 Jellyfin，修复或替换插件数据目录下的 strm-fingerprints.db，重新启动后再运行任务即可重试。 插件不会自动删除或重建损坏的状态库。

识别限制：同 URL 且没有可比 SHA-1 时，只有双侧有效字节 Size 不同才要求探测；信息不足只记录限制， 不凭空认定变化。修改时间本身不触发探测。
